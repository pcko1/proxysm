Authentication

All management endpoints require your admin password sent as a Bearer token. /health is public, and /rotate/{slug} uses the project API key via X-API-Key instead.

curl -H "Authorization: Bearer $PM_ADMIN_PASSWORD" \
  http://localhost:8080/api/v1/stats/overview

Endpoints

full schema in Swagger UI
GET/api/v1/ipspaginated

List proxies. Filter with pool_id, status, protocol or provider; sort with sort_by / sort_dir. Pagination via page and per_page (max 100).

{
  "data": [
    { "host": "185.42.118.20", "port": 8080, "protocol": "http", "last_health_status": "healthy" }
  ],
  "meta": { "total": 5151, "page": 1, "per_page": 50 }
}
POST/api/v1/ips/bulk

Bulk-import proxies from a newline-delimited list (host:port or user:pass@host:port), a structured proxy_list, or a subscription url. Protocols: http, https, socks5. Duplicates are skipped.

{
  "protocol": "http",
  "provider": "BrightData",
  "proxies": "user:pass@1.2.3.4:8080\n5.6.7.8:3128"
}
POST/api/v1/ips/{proxy_id}/check

Trigger an immediate health check for a single proxy and return the updated status.

DELETE/api/v1/ips/{proxy_id}

Delete a proxy. It is removed from every pool it belongs to. Returns 204 No Content.

GET/api/v1/poolspaginated

List pools with proxy counts and health summary. PATCH / DELETE /api/v1/pools/{pool_id} update or remove a pool.

POST/api/v1/pools

Create a pool with a rotation strategy: round_robin (default) or random.

{ "name": "us-residential", "rotation_strategy": "round_robin" }
POST/api/v1/pools/{pool_id}/ips

Add proxies to a pool by id: { "proxy_ids": ["…"] }. The same body on DELETE /api/v1/pools/{pool_id}/ips removes them.

POST/api/v1/projects

Create a project: { "name": "my-scraper" }. The response includes the generated slug and the plaintext api_key used as proxy credentials.

POST/api/v1/projects/{project_id}/pools

Assign pools to a project: { "pool_ids": ["…"] }. Unassign with DELETE /api/v1/projects/{project_id}/pools/{pool_id}.

POST/api/v1/projects/{project_id}/rotate-key

Generate a new API key for the project. The previous key is revoked immediately.

GET/api/v1/rotate/{project_slug}X-API-Key auth

Fetch the next proxy from the project's pools (by pool priority, using each pool's rotation strategy) — for clients that want raw proxy endpoints instead of the built-in gateway.

{ "host": "185.42.118.20", "port": 8080, "protocol": "http", "username": "user", "password": "pass" }
GET/api/v1/stats/overview

Fleet-wide counters: total / healthy / degraded / dead proxies, pools and projects. More under /api/v1/stats/*: status-codes, pool-metrics, top-domains, latency-trend, bandwidth-trend, provider-health…

GET/api/v1/stats/timeseries

Request volume over time. Query params: granularity (5min, 1hour, 1day) and hours of history.

GET/api/v1/healthno auth

Liveness probe. Returns 200 OK with { "status": "ok" } when the service is up.

Using the proxy

SLUG:KEY = project credentials

Route traffic through a project's pools using its slug:api_key as proxy credentials.

# HTTP / HTTPS — :{{ http_port }}
curl -x http://SLUG:KEY@localhost:{{ http_port }} https://httpbin.org/ip
# SOCKS5 — :{{ socks5_port }}
curl --proxy socks5://SLUG:KEY@localhost:{{ socks5_port }} https://httpbin.org/ip
